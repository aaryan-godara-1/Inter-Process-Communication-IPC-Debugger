# IPC Debugger

IPC Debugger is a mixed Node.js + Python codebase for modeling, visualizing, and analyzing inter-process communication behavior.

The current workspace contains two layers:

1. A Node.js application that powers the browser UI, simulation engine, live telemetry, and HTTP/WebSocket server.
2. A Python package that contains the original IPC debugger and analysis stack, including ETW-backed collection, simulation logic, and analytics.

## Purpose

The project is used to inspect IPC behavior, simulate contention scenarios, and explain system states such as normal flow, waiting, bottleneck, unsafe allocation, and deadlock.

The browser UI is the active front-end in this workspace. The Python package remains in the repository as a separate implementation layer and as a reusable backend/analysis package.

## Run The Node UI

```bash
npm start
```

Open:

```text
http://localhost:3000
```

| `package-lock.json` | Locked dependency tree for reproducible installs. Keep this file committed. |
| `server.js` | Thin Node entrypoint. It loads `server/server.js` and starts the application. |
| `README.md` | Top-level project documentation. This file is the canonical overview for the repository. |
| `client/` | Static browser shell and layout for the main UI. |
| `frontend/` | Client-side application logic that renders and updates the graph, controls, metrics, and analysis panels. |

| `ipc_debugger/` | Python package for the older debugger implementation and analysis pipeline. |
| `node_modules/` | Installed npm dependencies. Generated by `npm install` and not meant for editing. |
